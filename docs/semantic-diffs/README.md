# Semantic diffs

Written explanations of what a range of commits means: what changed for a
reader, which contracts and invariants moved, what was only a refactor,
and where the risk and test gaps are. Each report is checked against the
code, with commit messages used only as a statement of intent.

Reports are generated by the [Nightshift](https://github.com/marcus/nightshift)
`semantic-diff` task. They are documentation only and never change source
code. A report describes the tree at the time it was written; `path:line`
references are pinned to the last commit in its range.

Naming: `<date>-<from>-<to>.md`, where `<date>` is the day the report was
written (`YYYY-MM-DD`) and `<from>` / `<to>` are the short SHAs of the
first and last commits covered.
