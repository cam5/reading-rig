## 5. Notes by category

**Security/Privacy.** TD-101 is confirmed on `main`:
`auth.login.tsx:60-63` copies a form `redirectTo` into the magic-link URL,
and `auth.verify.tsx:45`/`:57` redirect to it after sign-in without
validating it. TD-102 relies on #223's audit and wasn't independently
reproduced here.

**Performance.** #212 added `?mode=paged` (`read.tsx:446-455`). Both modes'
hooks run on every render (`read.tsx:567`, `:592`, `:712`, `:722`). #248
measures about 0.28 ms per prepend at 5k rows. #214 (2026-09-30) describes
the same regression.

**Architecture/Design.** Size × churn hotspots (lines / commits in the last
90 days): `app/routes/read.tsx` 1258/23, `app/analytics.server.ts` 593/10.
Large, low-churn files: `lib/paged-columns/react/usePagedColumns.ts` 590,
`app/domain/api/openapi.server.ts` 469, `app/domain/epub/parseEpub.ts` 451
(tested), `app/domain/reading/handleReadAction.server.ts` 450,
`app/components/useVirtualizedRows.ts` 445.

## 7. How to re-run

```sh
git fetch origin && git rev-parse origin/main
# sizes
find app lib scripts prisma -name '*.ts*' -not -path '*/node_modules/*' \
  -not -path '*/generated/*' -not -path '*/build/*' | xargs wc -l | sort -rn | head -20
# debt markers
grep -rnE 'TODO|FIXME|HACK|XXX|@ts-ignore|@ts-expect-error|eslint-disable' \
  app lib scripts prisma --include='*.ts' --include='*.tsx'
# churn (90 days, non-test)
git log origin/main --since=90.days --name-only --format= -- app lib scripts prisma \
  | grep -E '\.tsx?$' | grep -v '\.test\.' | sort | uniq -c | sort -rn | head -15
# >200-line files with no matching test
for f in $(find app lib scripts -name '*.ts*' -not -name '*.test.*' \
  -not -path '*/__fixtures__/*' -not -path '*/generated/*'); do
  n=$(wc -l <"$f"); [ "$n" -gt 200 ] || continue
  b=${f%.*}; b=${b%.server}; ls ${b}*.test.ts* >/dev/null 2>&1 || echo "$n $f"
done | sort -rn
# backlog
gh pr list --state open --limit 100 \
  --json number,title,headRefName,baseRefName,createdAt,mergeable
gh issue list --state open --limit 50
# files shared by open PRs
for n in $(gh pr list --state open --limit 100 --json number --jq '.[].number'); do
  gh pr diff "$n" --name-only | sed "s/^/$n /"; done \
  | awk '{print $2}' | sort | uniq -c | sort -rn | awk '$1>2'
# required checks; hooks; db files
gh api repos/cam5/reading-rig/branches/main/protection/required_status_checks --jq .contexts
ls -la .git/hooks | grep -v sample
ls -la dev.db prisma/dev.db
```
